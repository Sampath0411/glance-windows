The InsightFace buffalo_s face-recognition model weights are NOT included in this
installer. On first run Glance downloads them from InsightFace's official release
and verifies the pinned SHA-256. Those weights are subject to separate
non-commercial, research-only terms; the Glance MIT license does not apply to or
remove restrictions on them. Do not use or redistribute the weights commercially
without separate permission.

This setup installs the Glance desktop application only. It does not install or
enable a Windows lock-screen credential provider. Normal Windows password and
PIN sign-in remain available. Enabling face unlock later requires administrator
approval from inside Glance. Downloaded models are stored in the signed-in user's
local app data, not in Program Files.
